# Agent instructions

Read the root `README.md` before any work. It is the single source of repository workflow, package boundaries and approval rules.

Work on task branches. Never publish, push, promote to main or add attribution trailers without the explicit authorization described there. Local ADR proposals in `docs/adr/` are ignored and are not accepted decisions.

## Commit attribution

Never add `Co-Authored-By` trailers or tool/AI authorship attribution to commits, pull requests or release notes. Preserve the owner's authorship. Inspect commit messages before a public push and remove any attribution trailers through an explicitly authorized history rewrite.
